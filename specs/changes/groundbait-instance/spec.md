# 窝料实例克重与自定义名称

Status: done

## Problem Statement

原生 item_def 的品类 46 窝料克重为 0，客户端按实例字段显示时会一直是“质量 0 克”。
制作界面填写的自定义名称也没有写入实例，产出后名称丢失。

## Solution

服务端按窝料档案把单件克重写进实例重量字段，并在启动修复中回填存量零值。
制作时把自定义名称写入物品实例名称字段。

## User Stories

1. 作为玩家，我希望成品窝料卡片显示实际单件重量。

2. 作为玩家，我希望制作时填写的名字在产出后保留。

3. 边界：旧存档里的零克重物品启动后自动修复。

## Implementation Decisions

- 模块：`internal/gameserver` 的物品物化、制作与启动修复。

- 重量：`unit_grams` 只影响实例显示，不参与窝料吸引公式。

- 缺省克重：档案缺项时使用 30 克。

- 自定义名称：写入 `phoglfnffah` 字段。

- 不改表结构，不写静态库。

## Testing Decisions

- 存储/行为：新实例克重、旧实例回填、自定义名称落库。

- 回滚后失败项：重量字段、修复版本和自定义名称断言。

## Out of Scope

- 不使用重量影响鱼口。

- 不改变配方产出数量。
