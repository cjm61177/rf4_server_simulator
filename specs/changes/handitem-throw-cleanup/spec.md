# 手持工具换弹与弹弓抛掷清理

Status: done

## Problem Statement

弹弓抛出后客户端可能残留旧装填物，切换弹药时同一格显示两份；805 响应缺少姿态块时，
客户端也无法正确更新时间与玩家姿态。额外抛出物实例如果默认下发，会和客户端自行绘制的饵团重复。

## Solution

换弹时将旧弹药从客户端弹药格移除并重新加入背包；805 继续下发姿态块，额外抛出物实例改为显式开启。
抛出物自清开关只在额外实例开启时生效。

## User Stories

1. 作为玩家，我希望连续切换两种窝料时弹药格只显示当前装填物。
2. 作为玩家，我希望抛出一发后客户端状态正常更新，不出现双份饵团。
3. 边界：关闭自清开关时，额外抛出物保持到 13/6 全量快照。

## Implementation Decisions

- 模块：`internal/gameserver` 的动态协议处理与装配结果。
- 协议：805 的 f2 为姿态块，f3 为物品更新，f4 为可选抛出物，f5 为移除 GUID。
- 缺省：`handitem_throw_pose=1`、`handitem_throw_projectile=0`、`handitem_throw_selfclean=0`。
- 换弹：旧装填物退回背包后，安排 4/21 移除和 4/22 重加。
- 兼容：客户端基线 4.0.25034。

## Testing Decisions

- 协议行为：装填物扣减、姿态块、默认无额外抛出物、显式开启后 f4/f5 关系。
- 换弹：旧弹药回包后确实回到背包，关闭刷新开关时保持旧行为。
- 回滚后失败项：缺省 no-projectile 断言、换弹移除重加和自清测试。

## Out of Scope

- 不修改客户端原生飞行方向计算。
- 不改变抛投距离和散布的玩法参数。
