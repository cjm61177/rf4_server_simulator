# PVA 饵料棒按实际填充料吸引鱼

Status: done

## Problem Statement

PVA 水溶网此前被当作植物饵参与食性计算，导致纯 PVA 网也产生窝效；
10/20/50 克规格实际填充 1/2/5 份干饵，但用料记录未按件数展开时比例会失真。

## Solution

PVA 水溶网作为惰性载体，不参与食性；棒内干饵、添加剂和香精按实际件数记录与合成。

## User Stories

1. 作为玩家，我希望 PVA 棒的吸引效果来自里面装的饵，而不是水溶网。

2. 作为玩家，我希望大棒和小棒按各自实际填充量计算。

3. 边界：纯 PVA 网不产生窝效。

## Implementation Decisions

- 模块：`internal/gameserver` 的制作用料记录与窝料档案合成。

- `hvz_pva_material` 作为载体直接跳过食性计算。

- 制作扣除多件原料时按实际件数重复记录，保持配方比例。

- 只有当窝格内没有任何有食性的用料时，才视为已知空饵并跳过吸引。

## Testing Decisions

- 单元：载体惰性、植物/动物填充分化、10/20/50 克规格用量。

- 行为：制作用料数量、投放账本冻结和运行时亲和。

- 回滚后失败项：纯 PVA 空饵、填充分化和规格比例测试。

## Out of Scope

- 不改变 PVA 物品克重显示和消耗时机。

- 不引入新的 PVA 配方。
