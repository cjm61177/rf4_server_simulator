# 修复上船黑屏与船票世界时钟锚点

Status: done

## Problem Statement

玩家使用有效船票上船时，客户端会反复请求 `3/7`，画面停在黑屏。
旧实现把票的 `oieepfcgjgn` 写成会话相对分钟，而客户端按世界纪元
总游戏分钟计算租期，导致有效票立即被判定为过期。复用旧有效票时，
服务端也没有同步替换客户端缓存中的票对象，修复后的锚点无法生效。

## Solution

船票锚点统一使用客户端世界时钟坐标；复用旧有效票时，根据票的租用
起始时间自动修复历史错误锚点，并通过 `4/21+4/22` 先更新客户端本地
票对象，再返回 `3/7` 验票结果。玩家无需重新购票即可正常上船。

## User Stories

1. 作为玩家，我使用有效船票靠近码头按 E，可以正常上船，不再停在黑屏。
2. 边界：旧存档中的票带着会话相对锚点时，首次复用时自动修复，不要求重新购票。
3. 边界：断线重连后复用仍有效的票，客户端与服务端使用同一世界时钟坐标。

## Implementation Decisions

- `internal/gameserver/boat.go`：`3/7` 新租用票写入
  `worldTotalGameMin(now)`；有效票复用时根据时效对象的租用起点反推
  世界时钟锚点，并保持原租期不续期。
- `internal/gameserver/boat.go`：复用有效票分支在返回响应前推送
  `4/21+4/22`，确保客户端替换本地票对象。
- 不修改字段形状、`args code`、数据库表或迁移；客户端基线仍为 `4.0.25034`。
- 回滚方式：revert 对应功能提交；历史错误锚点会在回滚后恢复原行为。

## Testing Decisions

- 协议/行为单元测试：`TestCheckTicket` 校验新租用票的激活字段和世界时钟锚点。
- 旧档兼容测试：`TestActiveRentalTicketRepairsLegacyWorldAnchor` 构造错误会话锚点，
  验证按站点复用有效票时自动修复。
- 实机回归：错误锚点票复用后，客户端停止重发 `3/7`，并上报 `3/10 boat_use 已上船`。
- 回滚后上述锚点断言和上船链路会重新失败。

## Out of Scope

- 船票购买价格、站点配置和租期定义调整。
- 船体、场景资源加载或客户端渲染修复。

## Further Notes

- `[事实]` 客户端运行时将票锚点与世界纪元游戏分钟比较，而不是会话相对分钟。
- `[事实]` 修复前有效票在客户端被判为负剩余；修复后实机上报 `3/10 boat_use 已上船`。
