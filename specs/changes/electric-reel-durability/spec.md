# 电轮耐久与锁轮三倍承力

Status: done

## Problem Statement

电轮已经有独立电机件（category 81，`rengine_1/rengine_2`），但当前耐久体系只算
摩擦片、齿轮、轴承、线杯、摇柄和轮油。电机既不参与本体耐久，也不影响锁轮承力，
换电机或电机磨损后不会改变电轮表现。

## Solution

电轮采用“机械件 + 电机”的混合耐久模型：

- 机械件继续沿用现有六件规则。
- 电机作为独立零件加入电轮本体耐久聚合和整机修理。
- 锁轮有效承力使用当前实装摩擦片与当前实装电机的实时值：

```text
机械承力 B = 当前摩擦片剩余制动力 × 本体倍率 × 轴承效率 × 齿轮效率
电机承力 M = 当前电机功率 × 功率折算系数 × 工艺 × 品质 × sqrt(电机耐久)
             × 轴承效率 × 齿轮效率 × 轮油传动系数
电轮锁轮值 E = 3.0 × min(B, M)
```

- 3 倍在最终取小后只乘一次。性能表重算、换件、修理、磨损都读取当前实装值，
  不缓存出厂值，也不会重复复利。
- 电机缺失或耐久归零时退回普通机械锁轮，保证手摇仍可用。
- 电机只在实际负载账中消耗：不参与每竿手摇基准，锁轮过载、泄力打滑、泡水和
  断件冲击会扣电机耐久。

## Implementation Decisions

### 1. 零件与聚合

| 零件 | 品类 | 电轮权重 | 熔断 |
| --- | ---: | ---: | --- |
| 摩擦片 | 9 | 0.20 | 是 |
| 齿轮 | 52 | 0.20 | 是 |
| 轴承 | 7 | 0.15 | 是 |
| 电机 | 81 | 0.25 | 否 |
| 线杯 | 8 | 0.08 | 是 |
| 摇柄 | 34 | 0.07 | 是 |
| 轮油 | 10 | 0.05 | 否 |

- 普通轮仍使用原六件权重，数值不变。
- 电轮聚合增加电机权重；电机为 0 只让电驱失效和本体下降，不直接把整轮判死。
- 整机修理和同型号修理恢复电机耐久为 1.0；换电机按新实例重算。

### 2. 电机承力与磨损

- 电机功率来自定义字段 `afmboidbbaj`，当前 `rengine_1/rengine_2` 为 33/47kg。
- `electric_motor_kg_per_power` 默认 1.0，保留实机校准空间。
- 电机有效承力随电机耐久按平方根衰减。
- 电机消耗矩阵：每竿基准 0；锁轮过载每秒 0.020%；泄力打滑每次 0.002%；
  泡水每竿 0.010%；断件冲击 0.05%。这些仍是初始标定，后续按日志调数值。

### 3. 热调与兼容

- `electric_locked_multiplier` 默认 3.0。
- `electric_motor_kg_per_power` 默认 1.0。
- 不新增协议字段、不改表结构。
- 现有 12 个 `elcon_*` 电轮自动识别；普通渔轮不进入新分支。

## Testing Decisions

- 新电轮锁轮值必须等于 `3 × min(机械承力, 电机承力)`。
- 修改摩擦片制动力后，锁轮值按新摩擦片实时变化。
- 换更强电机后，电机成为限制项时锁轮值按新电机实时变化。
- 连续同步性能表多次结果不变，不能复利叠乘。
- 电机耐久下降会降低本体聚合与锁轮承力，但不触发熔断。
- 电机耐久归零时锁轮退回普通机械值，手摇不失效。
- 普通渔轮锁轮公式保持原样。
- 整机修理把电机耐久恢复为 1.0。

## Out of Scope

- 不新做电池系统。
- 不改客户端电动模式 UI。
- 不新增客户端协议字段。
- 电动模式专用遥测尚未有第二份凭据，本版先覆盖已有负载账能证明的电机磨损。
