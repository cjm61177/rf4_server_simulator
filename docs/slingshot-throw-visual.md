# 弹弓抛饵协议与行为

## 命令链路

```text
13/4  拿起弹弓
13/1  装填一份窝料，服务端拆出装填子实例并写入弹弓的装填引用
13/5  抛出一发：服务端消耗装填子实例、写入窝料账本并返回 805
13/6  请求钓组全量快照
```

弹药格里真正被消耗的是 13/1 拆出的子实例，不是背包来源堆。

## 805 响应字段

805 / `lmbomkliaad` 包含抛投距离、散布百分比、姿态块、物品实例更新、可选抛出物实例和 GUID 移除数组。

该响应没有世界坐标或朝向字段。客户端自行计算飞行表现，服务端能够控制的是距离、散布和物品变化。

## 服务端行为

- 每发消耗装填槽中的一份，并写入窝料账本。

- 13/5 的窝料幂等键包含弹弓 GUID、会话号和 CallID。

- 额外抛出物实例缺省关闭，避免和客户端自行绘制的飞行饵重复。

- 姿态块缺省开启，用于客户端更新全局时间与玩家姿态。


## 可调参数

| 参数 | 缺省 | 说明 |
|---|---:|---|
| `handitem_throw_scatter` | 5.0 | 805 散布百分比 |
| `handitem_throw_pose` | 1 | 是否下发姿态块 |
| `handitem_throw_projectile` | 0 | 是否额外下发抛出物实例 |
| `handitem_throw_selfclean` | 0 | 抛出物是否同时进入移除数组 |

## 已知限制

原生客户端会根据本地瞄准状态生成饵团飞行方向。805 没有可下发的坐标或朝向，
因此服务端无法仅靠协议修正视觉方向；当前实现保证扣料、窝账和鱼口判定一致。

## 回归覆盖

- 805 六字段响应结构；

- 散布参数边界；

- 额外抛出物缺省关闭；

- 显式开启抛出物时的 f4/f5 关系。
