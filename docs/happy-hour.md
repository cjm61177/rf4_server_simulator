# 欢乐时光

资格跟随会员：管理员在玩家详情把会员设为“限时高级会员”（填写到期时间）或“永久会员”即自动获得欢乐时光，非会员没有资格；鱼群规则页的总开关仍可整体暂停加成。

不再有每日时长限制：会员在线钓鱼期间全程生效，不做累计或扣减，离线、暂停、遛鱼都不影响额度。同一角色的多个会话共享一份在线状态，同一时刻只有一个会话吃加成。限时会员到期后立即失效；永久会员不限时长。

生效时钓获基础经验额外增加50%，最终吃饵接受率相对提高10%，熟练度增长触发率相对提高25%并封顶95%。低兴趣鱼饵的最终接受率不超过10%，禁饵仍然排除；永久熟练度上限和单次增长量保持原规则。以上为本地玩法数值。

资料页的欢乐时光状态同样跟随会员：限时会员显示"进行中"并按会员剩余时间倒计时，永久会员显示"就绪"且不显示倒计时（客户端没有"不限时长"状态，状态 3 的文案只有剩余分钟与"剩余不到一分钟"）；非会员显示需要高级会员；总开关关闭时不再显示进行中。详见`specs/changes/happy-hour-membership/spec.md`。

资格在咬钩时随原鱼持久化，延后收鱼、结算失败重试或重新连接沿用原资格。额外经验按钓获基础经验计算并写入同一结算回执，客户端4.0.25034的经验细分使用既有kind57。管理页显示会员到期时间与剩余时长；数据库升级不改变已有等级、经验、金币或技能点。

本功能依赖原子钓获结算，资格随钓鱼快照保存；服务端和迁移测试覆盖资格与幂等性；游戏内活动图标及真实客户端表现仍需运行验收。
